# Local product photography demo

14 downloaded Pexels photographs replace development drawings for 320 sample products. Some photographs are reused across sample styles and color options; these are visual references, not verified HÀ NHI merchandise photographs. Product names, sizes, stock and prices are unchanged. Products remain PENDING_ASSETS.

Sources are recorded in sources.json and the MediaAsset table. License: https://www.pexels.com/legal-pages/license/

Run `pnpm exec tsx scripts/import-demo-photos.ts` to reapply the local demo mapping. Previous image associations are backed up in verification/backups/images-before-photo-demo-*.json. Detailed testing and unrelated fixes were paused at the user’s request.
